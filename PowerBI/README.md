# Power BI — HR Employee Attrition Dashboard

## 📌 Overview

This folder contains the Power BI implementation of the **HR Employee Attrition Analysis** project.

The dashboard transforms the analytical findings into an interactive business intelligence report that allows users to explore employee attrition across multiple dimensions.

## 📊 Dashboard KPIs

The dashboard presents three primary KPIs:

* **Total Employees:** 1,470
* **Attrition Count:** 237
* **Attrition Rate:** 16.12%

## 📈 Dashboard Visualizations

The report includes the following visualizations:

* Attrition Rate by Department
* Attrition Rate by Overtime
* Attrition Rate by Business Travel
* Attrition Rate by Job Role
* Attrition Rate by Job Satisfaction
* Attrition Rate by Age Group
* Attrition Rate by Years at Company

## 🎛️ Interactive Filters

Users can interact with the dashboard using slicers for:

* Department
* Business Travel
* Overtime
* Job Role

These filters allow users to analyze attrition patterns for specific employee groups.

## 📌 Key Findings

The dashboard highlights several important patterns:

* Employees working overtime have higher observed attrition.
* Frequent business travel is associated with higher attrition.
* Attrition varies significantly across departments and job roles.
* Lower job satisfaction is associated with higher observed attrition.

## 📁 File

The main Power BI report is:

`HR Employee Attrition Analysis.pbix`

## ▶️ How to Open

Download the `.pbix` file and open it using **Power BI Desktop**.

The dashboard is interactive when opened in Power BI Desktop, allowing users to use slicers and explore the visualizations.

## 🎯 Purpose

The dashboard is designed to convert analytical results into an easy-to-understand business reporting solution that can support HR workforce analysis and retention discussions.
